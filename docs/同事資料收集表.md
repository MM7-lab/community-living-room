# 社區客廳導覽地圖：同事資料收集表

多謝幫手！街坊用手機掃 QR code 就會睇到呢啲資料，所以請用**街坊睇得明嘅講法**，一句一樣，唔使寫長。
唔知或者未定嘅，寫「未定」就得，唔使估。

**填之前請留意（網頁係公開嘅）**
- 唔好寫街坊或者同事嘅全名、電話、私人資料。
- 相片唔可以有認得出樣嘅人。
- 未對外公布嘅安排唔好寫。

## 丙、各區提示（唔使全部答，有就寫）

### 地下

**1. 接待處**
- 當值同事可以幫街坊做啲咩？
- 同事介紹：每位寫職位、想公開嘅稱呼（例如「陳姑娘」，可以唔寫）、一兩句自我介紹。
- Board game：有邊幾款？點借？可唔可以帶走？
- 其他可以喺接待處借或者攞嘅嘢（例如雨傘、老花眼鏡、單張）。
- 牆上嗰部自助服務機同飲水機係做咩用、點用？

**2. 共聚飯廳**
- 可唔可以自己帶嘢食？有冇指定用膳時間或者共膳活動？
- 用完枱櫈要點執？

**3. 咖啡角（咖啡沖調設備區）**
- 咖啡係自己沖定由「街坊咖啡師」沖？幾時有？要唔要收費？
- 咖啡機、磨豆機街坊可唔可以自己用？
- 電腦：幾時擺好？可以用嚟做咩？一次用幾耐？要唔要登記？
- 尿袋（流動充電器）：有幾多個？點借？要唔要按金？可以借幾耐？
- 有冇充電線、插蘇位可以用？

**4. 休閒區同大電視**
- 電視可唔可以自己轉台或者播片？遙控喺邊？
- 梳化有冇使用守則（例如唔好瞓覺、飲食）？

**5. 兒童遊樂室（地下遊戲角）**
- 適合幾多歲？要唔要大人陪？要唔要除鞋？
- 玩具同圖書可唔可以借走？
- 清潔同消毒安排（街坊會關心）。

**6. 圖書閣**
- 實際喺邊個位？有咩類型嘅書？
- 可唔可以借走？點借點還？

**7. 社區廚房**
- 邊個可以用？要唔要預約或者上過課先用得？
- 食材、調味料、廚具係自己帶定有得用？
- 逐件設備嘅規矩：中島工作枱、靠牆長工作枱同洗手盆、電磁爐、黑色焗爐、白色蒸焗爐、牆架嗰部不鏽鋼機（請講埋佢係咩機）、黑色雪櫃、四門雪櫃、電飯煲、抽油煙罩。
- 雪櫃：可唔可以放私人食物？要唔要貼名同日期？放得幾耐？
- 用完清潔同倒垃圾嘅做法。
- 廚房裏面嗰部電視同枱椅（分享區）係點用？

**8. 洗衣及乾衣機**
- 邊個可以用？要唔要預約？
- 收費同付款方法（牆身付款機收咩：八達通、現金定其他？）。
- 洗衣粉係自己帶定有提供？
- 洗完幾耐要攞走？過時點處理？
- 邊啲嘢唔可以洗（例如被鋪、寵物用品）？

**9. 健康站**
- 量血壓機點用？有冇其他量度（例如體重、血糖）？
- 有冇護士或者同事幫手睇結果？幾時有？
- 數據會唔會記錄？

**10. 按摩椅**
- 一次可以用幾耐？要唔要登記或者收費？
- 邊啲人唔適合用（例如孕婦、有心臟起搏器）？

**11. 健身角**
- 有咩器材（啞鈴幾重、壺鈴、瑜伽磚、瑜伽墊）？
- 可唔可以自己用？有冇年齡限制？有冇教練或者運動班？

**12. 洗手間**
- 邊個係暢通易達洗手間？邊個有嬰兒換片枱？

**13. 兩道門同樓梯**
- 正門同右邊玻璃門各自幾時開？輪椅同嬰兒車用邊道？
- 上一樓有冇升降機或者其他無障礙安排？

### 一樓

**14. 活動室一（暫時做自修室）**
- 邊個可以用？開放時間？要唔要預約或者登記？
- 有幾多個位？有冇插蘇、Wi-Fi？
- 守則（例如保持安靜、飲食、留位）。
- 幾時會改做其他用途？

**15. 活動室二（自由空間）**
- 街坊或者團體可唔可以借場？點申請？
- 有咩可以借（枱、櫈、投影機、音響、白板）？
- 平時冇活動嗰陣可唔可以入去用？

## 丁、相片（有就最好）

每個區域一張橫度相，影到成個區域嘅樣。
- 唔好影到人樣、街坊或者同事嘅名、文件。
- 唔好影到機構標誌、品牌標誌同寫有地區名嘅海報。
- 手機相請先關閉位置資料先傳。
